## Open-source projects

- **[OpenAvatar](https://github.com/timesbye/OPEN-AVATAR)** — Unity/VRM avatars driven by structured LLM responses, with dialogue, expression and animation control. Supports Ollama and custom JSON APIs.
- **[ScamShield](https://github.com/timesbye/ScamShield-Gemma4)** — Android anti-scam prototype using local rules, Gemma-based analysis and web checks to explain risks in user-authorized messages and screen content.
- **[ReSearching Workflow Toolkit](https://github.com/timesbye/ALL-in-ALL_ReSearching_Workflow_Skill)** — Reusable Skill modules, prompts and project templates connecting literature review, ideation, experiment planning, figures, writing and review.
- **[Campus Interaction Platform](https://github.com/timesbye/campus-interaction-platform)** — JavaWeb learning template for accounts, task publishing, orders, comments, messaging and administration.
